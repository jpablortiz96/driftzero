Proof content hash is a SHA-256 over the DRIFTZERO canonical proof JSON, excluding its own content_hash field. It establishes content identity and detects alteration. It is not a digital signature, not an attestation, not a trusted timestamp, and not a ledger entry.

The downloaded file contains content_hash, so the SHA-256 of the whole file is expected to differ from it. Verifying the proof means re-canonicalising the document without that field.
